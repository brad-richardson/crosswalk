Join your city's data to the open map

A bridge table is a rosetta stone: it maps a city's own local road/path IDs ↔ Overture GERS ids, so any dataset keyed to those local IDs — crash records, pavement condition, permits, curb rules — becomes joinable to the open map in one line of SQL. One table per city retroactively unlocks all of that city's segment-keyed data.

This page shows per-release, per-dataset stats for the published bridge tables, read live from the published index.json. Head to Query & browse to run SQL or look up a GERS id, or see the worked join example and the Seattle sidewalk-hazards demo — a real city dataset (SDOT's open ADA defect queue) painted onto Overture geometry in one query.
